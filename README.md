# ig-customized-userscript
Userscript para Safari iOS que oculta reels y anuncios de Instagram para evitar el doomscrolling, con interfaz rosa porque me gusta el rosa

## Instalación

1. Instala [Userscripts](https://apps.apple.com/app/userscripts/id1463298887) desde la App Store (iOS 15 o superior).
2. Ajustes → Safari → Extensiones → activa Userscripts y permite instagram.com.
3. Abre la app Userscripts, elige una carpeta con **Set Userscripts Directory** y copia `instagram.user.js` ahí.
4. Abre instagram.com en Safari, inicia sesión y actívalo en **modo claro** (Más → Cambiar apariencia).
